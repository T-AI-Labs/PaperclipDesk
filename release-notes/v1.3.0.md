# PaperclipDesk 1.3.0

- An icon in the notification area brings the window forward with a click; its menu has the Company, New and Go to menus of the menu bar, the settings and Quit. The gear turns it off.
- Errors pop up at the top right with their cause and a button to the log, for instance when the local server cannot start or stops. The gear turns the pop-ups off; the bell lists the errors and warnings either way.
- Uninstalling PaperclipDesk removes everything it kept: settings, remotes, logs, the local server with its companies and backups, the browser profiles and the downloaded server. Updates keep all of it.
- The Go to menu no longer offers the review queue and learnings, which Paperclip only shows with its experimental pipelines turned on.
- The zoom in the gear takes any percentage you type, from 30 to 300, besides the steps of the − and + buttons.
- New installations start with the WinUI 3 design.
