# PaperclipDesk 1.4.0

- All updates are in one place: **Updates …** in the gear shows the version of PaperclipDesk and of the local Paperclip server, searches for newer ones and installs them. A dot on the gear says when a new version of the app is out.
- The Paperclip server 2026.1023.0 starts. Its package lacked a library the server needs and stopped at once; the rebuilt package brings Claude Opus 5.5 and Sonnet 5.5 to the agents. If you installed it already, **Gear → Local server … → Reinstall** fetches the fixed one.
- A template that asks for a GitHub token takes it from the GitHub CLI when you are signed in there with `gh`; a switch in the import turns that off. The token goes straight to Paperclip, which keeps it as a secret.
- The Help menu is shorter: the log, the data folder and the developer tools are under **Troubleshooting**.
- The Company menu says **New company from template …**.
